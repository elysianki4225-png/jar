# ModLingo

给 Minecraft Mod 翻译语言文件用的小工具。纯前端，JAR / ZIP 的解包、编辑、打包全在浏览器里做，文件不会传到任何服务器。

## 怎么访问

最常用的是开发模式，改代码能直接刷新：

```bash
npm install
npm run dev
```

终端里会打印地址，一般是 http://localhost:5173 。dev 服务监听的是 `0.0.0.0`，同一个局域网里的手机或别的电脑可以用 `http://<你的电脑IP>:5173` 打开。端口被占的话 Vite 会自己换一个，以终端输出为准。

想看接近线上的版本，就构建一次再预览：

```bash
npm run build
npm run preview
```

预览默认在 http://localhost:4173 。

如果不想起服务，`npm run build` 之后直接双击 `dist/index.html` 就能用。构建产物用的是相对路径，所以放到任意子目录下也能访问，比如直接丢到静态服务器的某个文件夹里。注意 dev 模式下没有 `dist`，这个方法只适用于构建产物。

## 使用

打开页面后可以先点一下示例工程体验。要处理真实的 Mod，点「打开 Mod」或者直接把 `.jar` / `.zip` 拖进页面。目前识别 `assets/<命名空间>/lang/` 下的 `.json` 和 `.lang` 文件。

几个容易踩的地方：

- 单个 Mod 文件上限 300 MB，单个语言文件上限 24 MB，超了会直接拒绝或跳过。
- 编辑内容在打包之前只存在当前页面里。刷新或关闭标签页前会有提醒，别嫌烦。
- 打开新的 Mod 会清空还没打包的修改，这一点会弹确认框。

## 已包含

- 多语言文件扫描、源语言 / 目标语言切换，以及新建目标语言文件
- 词条搜索、分页，按待翻译 / 已完成 / 占位符检查筛选
- 单条编辑、批量复制原文或清空，导入已有的 `.json` / `.lang` 译文
- 下载目标语言文件，或者把译文写回原来的 `.jar` / `.zip`（其他文件原样保留）
- 拖放导入、快捷键（`/` 搜索，`Ctrl+Enter` 跳到下一条待翻译）、占位符一致性提示

## 遇到问题

页面没样式或者按钮没反应，先检查两件事：是不是还在用旧的 `dist`（重新跑一次 `npm run build`），或者是 dev 服务已经退出了。还不行的话开控制台看一下报错，开 issue 的时候把报错贴上来就行。

占位符检查目前只认 `%s`、`%d`、`%1$s`、`%.2f` 这类 printf 风格和 `{name}` 风格，别的写法可能会漏报。
