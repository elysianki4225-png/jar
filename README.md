# ModLingo

一个纯前端的 Minecraft Mod 语言文件工作台。JAR / ZIP 解包、词条编辑与打包都在浏览器本地完成，不会上传文件。

## 开发

```bash
npm install
npm run dev
```

打开页面后可用示例工程体验；点击「打开 Mod」载入 `.jar` / `.zip`。支持 `assets/<命名空间>/lang/` 下的 `.json` 与 `.lang` 文件。

## 已包含

- 多语言文件扫描、源语言 / 目标语言切换与新语言文件创建
- 词条搜索、分页、待翻译 / 已完成 / 占位符检查筛选
- 单条编辑、批量复制原文 / 清空、导入现有 `.json` / `.lang` 翻译
- 下载目标语言文件、保留 Mod 其他文件并打包回 `.jar` / `.zip`
- 拖放导入、快捷键、占位符一致性提示
